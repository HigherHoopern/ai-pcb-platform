## 一、项目概述与应用场景

### 1.1 项目背景
在家庭住宅、机房服务器机柜、仓储仓库及工业配电房中，温度过高、湿度失控以及初期火灾引起的烟雾散逸是造成设备损坏和安全事故的主要诱因。本项目旨在设计一款**高可靠、低成本、体积紧凑的智能环境监测与烟雾报警器**，集“温湿度实时采集、烟雾浓度连续监测、OLED 本地状态显示、双重声光急促报警与人机按键交互”于一体。

### 1.2 核心目标
1. **硬件设计**：采用标准双层板（2-Layer ENIG 沉金 1.2mm），满足嘉立创工业级制造规范与 EMC/ESD 防护要求；
2. **嵌入式固件**：基于 ARM Cortex-M0+ 架构（STM32G030 / STM32L011），以模块化纯 C 语言编写，具备低功耗待机、传感器滤波与防误触报警算法；
3. **闭环交付**：通过 KiCad 官方 DRC 0 违规验证，输出完整可直接打样的 Gerber、BOM 及坐标文件。

## 三、硬件设计详细规格与技术指标

### 3.1 供电与电源完整性 (PI)
1. **输入电源**：
   - 接口：标准 USB Type-C 16-Pin 贴片母座（带 CC1/CC2 5.1kΩ 下拉电阻，兼容所有快充头 5V 握手）；
   - 输入耐压：4.5V ~ 6.0V DC；
2. **保护机制**：
   - **防反接**：东芝低阈值 P-MOSFET（`SSM3J328R`，SOT-23），导通电阻仅 50mΩ，彻底杜绝输入接反烧毁元件；
   - **ESD 防护**：输入端集成 `USBLC6-2SC6` TVS 阵列，提供 ±15kV 空气放电及 ±8kV 接触放电防护；
   - **自恢复保险丝**：板载 500mA PPTC 贴片保险丝，过流自动阻断。
3. **稳压电路**：
   - LDO 型号：`ME6211C33M5G-N` (SOT-23-5)；
   - 输出电压：3.3V ±1%，最大连续输出电流 500mA，低纹波 (< 30µVrms)；
   - 去耦滤波：输入与输出各配置 10µF 0805 X5R 陶瓷电容并联 100nF 0402 高频去耦电容。

### 3.2 传感器子系统
1. **温湿度传感器 (U4 - SHT30 / AHT20)**：
   - 通信协议：标准 I2C（最高速率 400kHz，板载 4.7kΩ 上拉电阻）；
   - 温度范围：-40℃ ~ +125℃，典型精度 ±0.3℃；
   - 湿度范围：0% ~ 100% RH，典型精度 ±2% RH；
   - 布局要求：远离 MQ-2 发热体和 LDO 稳压器，PCB 边缘布置隔离镂空槽（热隔离隔离岛），防止板上传导热导致温测偏高。
2. **烟雾与可燃气体传感器 (U5 - MQ-2 / MQ-2B)**：
   - 敏感气体：液化气、丙烷、氢气、烟雾及可燃蒸气；
   - 驱动要求：加热丝供电需要 5V，回路配置 1kΩ~47kΩ 可调负载电阻 $R_L$；
   - 输出架构：
     - **模拟输出 (AO)**：连接至 MCU `PA0 (ADC_IN0)`，12-Bit 连续采样浓度；
     - **数字比较输出 (DO)**：板载 LM393 比较器与精密多圈电位器，输出低电平有效的中断信号至 MCU `PA1 (EXTI1)`。

### 3.3 人机交互与声光报警
1. **显示单元 (DISP1 - 0.96寸 OLED)**：
   - 分辨率：128 × 64 点阵，单色（白光或蓝光）；
   - 驱动芯片：SSD1306，采用 4-Pin 2.54mm 排母/排针封装插拔或 0.5mm 间距 FPC 焊接；
   - 接口：I2C 接口，与 SHT30 复用总线（SHT30 地址 0x44，OLED 地址 0x3C）。
2. **声音报警 (BZ1)**：
   - 型号：3.3V 贴片/直插式电磁蜂鸣器（9.0×9.0mm 或 12×12mm）；
   - 驱动电路：由 S8050 NPN 三极管或 SI2302 N-MOSFET 低端开关驱动，MCU `PA2` 输出 2.7kHz PWM 信号，蜂鸣器并联 1N4148 续流二极管。
3. **LED 状态指示**：
   - `LED_RUN` (绿色 0603)：系统正常运行每 2 秒呼吸慢闪一次；
   - `LED_ALARM` (红色 0603)：烟雾或温度超限时 5Hz 急促快闪。
4. **用户操作按键**：
   - `KEY1` (消音/校准)：短按消除当前报警蜂鸣，长按 3 秒进入传感器零点校准；
   - `KEY2` (翻页/自检)：短按切换 OLED 页面（当前参数 / 历史极值 / 阈值设置），长按 2 秒启动蜂鸣器与 LED 声光自检。

## 四、机械结构与 PCB 工艺规范

1. **外形尺寸**：
   - 物理尺寸：**65.0 mm × 45.0 mm**，矩形结构；
   - 四角倒角：**R 3.0 mm**，便于装配入标准化注塑外壳；
   - 定位孔：4 个 **Ø2.5 mm 镀锡固定安装孔**（孔心距板边 3.5mm，周围布置 4.5mm 禁布阻焊开窗）。
2. **PCB 叠层与板厚**：
   - 层数：**2 层板 (Top: 元器件与信号布线, Bottom: 完整 GND 铺铜与辅助布线)**；
   - 板厚：**1.2 mm**（兼顾结构刚度与轻薄度）；
   - 铜厚：1 oz (35µm)；
   - 表面工艺：**沉金 (ENIG)**，抗氧化、焊接平整度高；
   - 阻焊颜色：哑光黑 (Matte Black) 或 工业绿 (Industrial Green)。
3. **布局布线军规 (DFM)**：
   - **45° 钝角走线**：严禁 90° 直角与锐角，走线拐角倒角平滑；
   - **线宽标准**：
     - 5V 电源主干：≥ 0.8 mm (30 mil)；
     - 3.3V 电源线：≥ 0.5 mm (20 mil)；
     - 信号走线：0.2 mm (8 mil)，最小间距 ≥ 0.2 mm (8 mil)；
   - **法拉第屏蔽笼**：PCB 外沿环绕一圈 3.0 mm 间距的接地缝合过孔（GND Via Fence）；
   - **热设计与气流**：MQ-2 传感器发热丝位于板卡边缘，下方及周围开槽，严禁与 MCU 和温湿度传感器处于同一热岛。

## 五、嵌入式固件架构与软件功能规范

### 5.1 固件技术栈
* **架构**：模块化裸机状态机（协作式时间片轮询）或 FreeRTOS；
* **编程语言**：纯 C 语言（C99 标准）；
* **编译器**：ARM GCC (`arm-none-eabi-gcc 16.2.0`)；
* **构建系统**：Makefile 与 CMake 双支持。

### 5.2 软件核心模块划分
1. **BSP 驱动层**：
   - `bsp_i2c.c`：硬件/模拟 I2C 驱动，实现超时保护机制；
   - `bsp_sht30.c`：SHT30 循环测量读取与 CRC8 校验算法；
   - `bsp_adc.c`：DMA 循环采集 MQ-2 烟雾传感器电压值；
   - `bsp_oled.c`：SSD1306 显存刷新与 GUI 基础点阵字库渲染；
   - `bsp_buzzer.c`：TIM PWM 变频脉冲生成驱动。
2. **算法与处理层**：
   - **滑动均值滤波 (Moving Average Filter)**：对 ADC 采集到的烟雾电压与温度数据执行 16 次均值滤波，消除工频扰动；
   - **滞回比较报警算法 (Hysteresis)**：设置 5% 的报警恢复死区，防止在阈值临界点产生频繁声光震荡；
   - **按键去抖与长短按状态机**：软件 20ms 延时去抖，区分单击与长按事件。
3. **应用状态机 (System State Machine)**：
   - `STATE_NORMAL`：正常监测态，绿灯呼吸，OLED 显示当前温湿度与烟雾 PPM；
   - `STATE_ALARM_SMOKE`：烟雾超限火警态，红灯急促快闪，蜂鸣器 2.7kHz 间歇尖叫；
   - `STATE_ALARM_TEMP`：温度超限高温预警态，红灯常亮，蜂鸣器慢速长鸣；
   - `STATE_MUTED`：消音态，蜂鸣器静音 120 秒，红灯保持闪烁直至浓度回落；
   - `STATE_SELF_TEST`：自检态，全屏点亮、LED 循环、蜂鸣器鸣响 2 秒后复位。
