# 电路板与嵌入式系统设计需求清单 (Hardware & Embedded Requirement Checklist)
> **填写指引**：在启动任何 PCB 与嵌入式开发之前，用户只需对照此清单填写或提供自然语言描述，平台 AI Agent 将自动将其解析为标准的工程参数模型 (`spec.json`)。

---

## 1. 结构与机械尺寸需求 (必填)

* [ ] **PCB 板框尺寸**：
  - 形状：矩形 / 圆形 / 异形（如有结构图 CAD/DXF/PDF 请直接上传）
  - 几何尺寸：长 (mm) × 宽 (mm) × 厚度 (通常为 1.0mm / 1.6mm)
  - 板框公差：如 $\pm 0.1\text{mm}$ 或 $0 / -0.4\text{mm}$
* [ ] **机械结构避让与定位**：
  - 安装螺丝孔：数量、直径（如 $\phi 2.0\text{mm}$ / $\phi 3.0\text{mm}$）、定位坐标
  - 倒角/圆角要求：四角半径（如 R1.0mm）
  - 异形避让：是否有外壳卡槽、镜头缺口、按键开孔等（如中心 $\phi 3.5\text{mm}$ 半圆缺口）
* [ ] **元器件限高与空间禁布区 (Keepout)**：
  - 正面限高：最大允许元件高度（如 $H \le 5.0\text{mm}$）
  - 背面限高：背面贴片或引脚高度限制（如 $H \le 1.3\text{mm}$ 或单面贴片要求）
  - 边缘禁布区：板边缘内缩多少禁止布元器件与走线（如板边 2.0mm 禁布）

---

## 2. 电源系统与供电规格 (必填)

* [ ] **输入供电源**：
  - 供电类型：单节锂电池 (3.0~4.2V) / 干电池 (1.2~3.0V) / USB Type-C 5V / DC 适配器 (9V/12V/24V)
  - 电池接口形式：板载焊线焊盘 (P+/P-) / 接插件座子 (如 JST-PH2.0) / 弹片触点
* [ ] **内部电压轨与负载能力**：
  - 系统核心电压：如 3.3V (给 MCU 与数字传感器)
  - 升压/特殊驱动：如是否需要 Boost 升压（如 3.0V 升至 5V/12V/高压驱动）
  - 最大工作电流与峰值电流（如主回路最大 500mA，瞬间脉冲 1.5A）
* [ ] **功耗控制与续航要求**：
  - 工作状态功耗目标（如 $< 100\text{mA}$）
  - 待机/低功耗休眠电流上限（如待机 $< 10\mu\text{A}$）
* [ ] **电气防护机制**：
  - 是否需要电池防反接保护（PMOS 理想二极管 / 肖特基二极管）
  - 是否需要过流自恢复保险丝 (PTC)
  - 是否需要防静电 ESD/TVS 保护（特别是在人手可触碰的外露按键与接口处）

---

## 3. 主控芯片与固件开发架构 (必填)

* [ ] **主控 MCU / SoC 偏好**：
  - 指定型号（如 STM32L011F4U6TR、ESP32-S3、RP2040、nRF52840）或由平台根据引脚与算力自动推荐
  - 封装要求（如超紧凑 QFN-20 / 便于手工焊接的 TSSOP / LQFP）
* [ ] **烧录与调试接口**：
  - 调试协议：SWD (SWDIO/SWCLK/NRST/GND) / JTAG / 串口串口下载
  - 调试接口形式：板边测试点 (Test Points) / 间距 1.27/2.54mm 排针 / Type-C DFU
* [ ] **固件开发框架与语言**：
  - 纯嵌入式 C (裸机 Register / LL / HAL)
  - RTOS 实时操作系统 (FreeRTOS / RT-Thread)
  - 构建系统要求：Makefile (arm-none-eabi-gcc) / CMake / Keil MDK / PlatformIO

---

## 4. 外设功能与接口定义 (按需勾选)

* [ ] **人机交互 (UI/UX)**：
  - 按键/开关：轻触按键、长按短按逻辑、多档位拨动开关、磁感应干簧管 (Reed Switch)
  - 指示灯：单色 LED、双色 LED、RGB 状态呼吸灯、跑马灯等状态指示模式
  - 屏幕/显示：OLED (0.96寸 I2C/SPI)、电子墨水屏、TFT 彩屏
* [ ] **环境检测与传感器**：
  - 光照检测：光敏电阻 (LDR) ADC 采集 / 数字环境光芯片
  - 运动姿态：六轴陀螺仪加速度计 (IMU, 如 MPU6050 / ICM-42688)
  - 温湿度/气压：SHT40 / BMP280
* [ ] **功率驱动与执行器**：
  - 红外补光灯 / 补光照明 (MOS 管低边 PWM 驱动)
  - 蜂鸣器 (无源 PWM 音调 / 有源蜂鸣器)
  - 步进电机 / 舵机 / 电磁阀控制回路
* [ ] **对外引线与接插件 (Wiring Pads & Connectors)**：
  - 对外焊线数量与功能（如 15 组焊盘：电源、电机、传感器、按键引出）
  - 穿线孔（是否需要在焊盘旁增加 $\phi 0.8\text{mm}$ 的穿线固定孔以防拉扯脱焊）
  - 丝印极性防呆标识（必须在焊盘旁标注极性与功能名称，如 BAT+、IR- 等）

---

## 5. PCB 制造工艺与制造厂要求 (选填，默认最优)

* [ ] **目标板厂**：默认首选嘉立创 (JLCPCB) 标准工艺（免加价经济档）
* [ ] **PCB 层数**：
  - 2 层板（经济打样首选，双面铺铜）
  - 4 层板（高密阻抗控制，推荐内层 GND + PWR）
* [ ] **板材与表面处理**：
  - 板材：FR-4
  - 表面工艺：沉金 (ENIG, 推荐高可靠与高平整度) / 有铅喷锡 (HASL) / 无铅喷锡
  - 铜厚：常规 1oz (35μm)
* [ ] **阻焊油墨与丝印颜色**：
  - 阻焊：绿色（默认工艺最佳）/ 哑光黑 / 蓝色 / 红色 / 白色
  - 丝印：白色（与深色底色对比鲜明）
* [ ] **贴片生产形式**：
  - 仅做 PCB 空板，手工焊接
  - 包含 SMT 贴片加工（自动输出标准 BOM 与 Pick-and-Place 坐标表）

---

## 6. 特殊工况与可靠性要求 (选填)

* [ ] **工作环境**：常规室内 (0~50℃) / 户外工业级 (-40~85℃)
* [ ] **电磁防护与法拉第笼**：是否处于金属封闭腔体内部，是否需要板边高密缝合地孔（法拉第屏蔽笼）防止静电打火
* [ ] **模拟数字隔离**：是否有敏感微弱模拟信号（ADC 采样），需严格与开关电源 SW 节点进行物理隔离

---

## 7. 需求输入范例 (User Input Template)

用户在与平台 AI 对话时，只需发送如下格式简明文字即可直接开工：
```text
【项目名称】：双筒夜视仪单管驱动板 LAB7
【尺寸要求】：59x26mm，板厚1.0mm，四角R1倒角，底边中间有一个φ3.5mm避让缺口。
【供电规格】：1.5V干电池供电，经Boost升压到3.3V给系统供电，同时输出高压驱动夜视管。
【主控方案】：STM32L011 QFN-20，C语言裸机开发，提供 SWD 调试点。
【主要外设】：
  1. 1个干簧管磁控开关（主电源关断）；
  2. 2档位拨动开关（1档开机，2档开红外补光）；
  3. 1个光敏电阻用于环境光强弱检测；
  4. 红/黄 2颗状态指示灯；
  5. 15个对外穿线焊接盘（带防拉扯穿线孔与丝印功能极性标注）。
【工艺要求】：嘉立创2层沉金板，板边做防静电地孔屏蔽圈，输出完整打样Gerber和固件源码。
```
