# PCB 硬件工程与 DFM 智造工艺速查卡
**基于《嘉立创 从设计到量产：电子工程师PCB智造实战指南》核心数据整理**

## 1. 文档与工艺体系概览

本速查卡基于嘉立创（JLCPCB）标准工艺体系，涵盖从设计（EDA）到制造（CAM/PCB）及组装（SMT）的全流程关键参数。

*   **设计软件生态**：
    *   **嘉立创 EDA**：永久免费，集成百万级封装库，支持原理图、PCB、3D 外壳设计，支持一键下单。
    *   **主流兼容**：Altium Designer (AD), PADS, Gerber 格式。
*   **制造软件生态**：
    *   **嘉立创 DFM**：免费在线/客户端工具，支持 PCB 与 SMT 双重分析，提供 BOM 匹配与坐标文件校验。
    *   **嘉立创 CAM**：后端制造数据转换与工艺评估。
*   **核心工艺红线原则**：
    *   **常规 vs 极限**：常规参数保证良率与成本，极限参数需评估且可能产生额外费用。
    *   **公差意识**：所有尺寸设计必须预留制造公差（如锣边 ±0.2mm，钻孔 ±0.05mm 等）。
    *   **材料一致性**：1.6mm FR-4 双面板标准含 8 张玻纤布，少于 8 张视为减料。

| 盎司 (oz) | 厚度 (μm) | 厚度 (mil) | 适用场景 |
| :--- | :--- | :--- | :--- |

*   **换算公式**：1 oz ≈ 28.35g 铜 / ft²；1 mil = 25.4 μm。
*   **成品铜厚限制**：
    *   双面板：1oz, 2oz, 3oz, 4.5oz (需评估)。

### 2.3 阻抗控制参考 (需结合具体叠层)

*   **推荐工具**：使用嘉立创“阻抗计算神器”输入层压结构，获取推荐叠层。
*   **常见结构示例**：
    *   JLC04161H-3313A: 成品板厚 1.58mm ±10%，外层 1oz。
    *   JLC04161H-3313: 成品板厚 1.56mm ±10%，外层 1oz。
*   **注意**：阻抗对层间介质厚度、线宽、介电常数 (Dk) 敏感，设计时需预留公差。

## 5. 激光钢网开口、SMT 贴片元器件封装间距与回流焊/波峰焊工艺红线

### 5.1 钢网 (Stencil) 与开口

*   **钢网厚度**：常规 0.10mm - 0.15mm (根据元件高度和焊盘大小选择)。
*   **开口公差**：激光切割精度通常在 ±0.02mm 以内。
*   **开口形状**：
    *   矩形元件：开口比焊盘小 0.05-0.10mm (单边)，防止锡膏溢出。
    *   BGA/QFN：开口通常为圆形或方形，直径/边长略小于焊盘，或采用“田”字格/十字格以利于排气。
    *   **注意**：书中未提供具体钢网开口公式，但强调 SMT 分析需检查钢网文件与 PCB 焊盘匹配性。

### 5.2 SMT 贴片元器件封装间距红线

| 参数项 | 最小值/推荐值 | 备注 |
| :--- | :--- | :--- |
| **0402/0603 元件间距** | ≥ 0.20 mm | 小于此值需特殊工艺或人工 |
| **QFN 底部焊盘间距** | ≥ 0.10 mm | 需确保回流焊排气 |
| **BGA 球间距** | ≥ 0.30 mm | 常规 BGA 最小间距 |
| **元件与板边距离** | ≥ 0.50 mm | 防止贴片机吸嘴干涉 |
| **元件与 V-CUT 线距离** | ≥ 1.00 mm | 防止分板应力损坏元件 |
| **高密度区域** | 避免在焊盘间走线 | 焊盘间距 <0.5mm 时，中间严禁走线 |

### 5.3 回流焊 (Reflow) 与波峰焊 (Wave Soldering) 工艺红线

*   **回流焊**：
    *   **共面性**：BGA/QFN 焊盘共面性要求高，喷锡工艺不适合高密度 BGA，推荐沉金或 OSP。
    *   **温度曲线**：根据锡膏类型（无铅/有铅）调整，峰值温度通常 235-245°C (无铅)。
    *   **预热**：防止热冲击导致元件脱落或 PCB 翘曲。
*   **波峰焊**：
    *   **适用性**：主要用于通孔元件 (THT) 或混合组装。
    *   **防桥接**：SMT 元件需涂覆防焊胶 (Flux Barrier) 或使用波峰焊挡板。
    *   **板厚限制**：波峰焊对厚板 (>2.0mm) 加热均匀性要求高，需评估。
    *   **最小插件孔**：≥ 0.50
