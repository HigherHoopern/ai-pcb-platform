# 电源完整性与 DC-DC 开关电源布线军规

## 1. 概述
在现代嵌入式设备中，80% 以上的系统死机、复位、ADC 读数跳动和 EMC 辐射超标，源于**电源分配网络（PDN）设计不当或 DC-DC 开关电源布线缺陷**。
本手册针对升压（Boost）、降压（Buck）、LDO 以及主供电退耦提供工业级硬核布局布线规范。

---

## 2. 核心命脉：最小化“热回路”（Hot Loop）

### 2.1 什么是热回路？
在开关电源中，电流在开关管交替导通/关断瞬间发生极高变化率（高 $di/dt$）的环路称为**热回路（Hot Loop）**。
根据法拉第电磁感应定律：
$$V_{\text{noise}} = L_{\text{parasitic}} \cdot \frac{di}{dt}$$
如果热回路面积大、寄生电感 $L$ 大，就会在电路中激发几十兆甚至几百兆赫兹的高频尖峰电压和强烈磁场辐射！

### 2.2 Buck（降压）vs Boost（升压）热回路辨识对比

```
【Buck 降压转换器】                       【Boost 升压转换器】
   VIN ──┬──[SW1]──┬──[L1]── VOUT          VIN ──[L1]──┬──[D1/SW2]──┬── VOUT
         │         │                                   │            │
       [CIN]     [SW2/D1]                            [SW1]        [COUT]
         │         │                                   │            │
   GND ──┴─────────┴──────── GND           GND ────────┴────────────┴── GND
  ▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲                     ▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲▲
  【Buck 的热回路在 输入侧 CIN】           【Boost 的热回路在 输出侧 COUT】
  高频交流电流只在 CIN-SW1-SW2 间剧烈流动！  高频交流电流只在 SW1-D1-COUT 间剧烈流动！
```

- **Buck 布局铁律**：**输入电容（CIN）必须紧贴芯片的 VIN 和 PGND 引脚**，走线优先最短表层直连，不得经过过孔！
- **Boost 布局铁律**：**输出储能滤波电容（COUT）必须紧贴芯片的 VOUT 和 PGND 引脚**，环路面积压缩到 1mm 级别以内！

## 3. 开关节点（SW Node）的“尺寸权衡”

### 3.1 矛盾对立点
- **高 dv/dt 噪声**：SW 节点电压在 0V 和高压之间以纳秒级速度极速跳变，巨大的电场变化率使其相当于一个辐射天线，**面积越小辐射越低**；
- **大电流与散热**：SW 节点承载全部开关电流，且连接功率开关管，**铜皮太窄会导致发热过大、阻抗增加**。

### 3.2 黄金折中法则
1. **短而粗的矩形铜皮**：SW 铜皮长度尽量短（电感紧靠芯片引脚），宽度满足载流（1mm 宽可走约 1.5~2A）；
2. **禁止大面积无节制铺铜**：严禁将 SW 节点任意漫延或大面积填充到底层；
3. **禁止敏感信号穿行**：SW 节点正下方内层必须是完整 GND 屏蔽，**严禁任何时钟线、模拟信号线、复位线或反馈走线从其正下方穿过**。

## 4. 电压反馈（FB）走线防护规范

FB 引脚是高阻抗模拟敏感引脚，极易感应外界空间电磁场或电感漏磁，导致输出电压抖动甚至系统失稳振荡。

### 4.1 反馈走线 4 大禁忌与规范
1. **采样点位置**：FB 取样点必须取自**输出滤波电容的最远端（远离芯片侧）**，感知最平稳的滤波后电压，严禁在芯片输出管脚或电感端直接取样；
2. **分压电阻就近放置**：上分压与下分压电阻必须**紧挨芯片的 FB 和 AGND 管脚**，走短线进芯片；
3. **空间绝对隔离**：FB 走线必须与电感、二极管、SW 节点保持至少 **3mm 以上**物理间距；
4. **包地或内层屏蔽**：若板卡空间拥挤，FB 走线应打过孔进入内层（上下均为完整 GND 平面），或在表层进行左右伴随包地（Guard Ring）。

## 5. 去耦电容（Decoupling Capacitor）布局与过孔优化

### 5.1 容值搭配与放置原则
- **大小电容组合**：例如 10µF（储能，吸收低频波动）+ 100nF（高频低阻抗）+ 100pF（吸收射频毛刺）；
- **就近顺流原则**：供电走线必须**先流经大电容，再流经小电容，最后注入芯片引脚**。小电容（100nF/10pF）距离引脚越近，引线电感越小，高频滤波截止频率越高。

### 5.2 去耦电容过孔打法对比（阻抗优化）
```
  [ 极差：长走线引出打孔 ]    [ 较好：引脚旁打孔 ]       [ 最优：焊盘侧边双过孔并联 ]
     Pad ───长细线───(○)Via     Pad ──短粗线──(○)Via       (○) ── Pad ── (○)
      (电感巨大，高频失效)       (寄生电感约 0.8nH)        (双过孔并联，电感 < 0.3nH)
```
- **黄金法则**：过孔打在电容焊盘内侧或侧边，走线短而粗（线宽 ≥ 0.3~0.5mm），禁止从电容引出一条细线再打孔接地。

## 6. 电流承载能力与过孔载流计算

### 6.1 走线温升载流能力（参考 IPC-2152 标准，1 oz 铜厚，温升 10°C）
- **0.25 mm (10 mil)**: 约 0.8 A
- **0.50 mm (20 mil)**: 约 1.5 A
- **1.00 mm (40 mil)**: 约 2.5 A
- **2.00 mm (80 mil)**: 约 4.0 A

### 6.2 导电过孔载流与散热
- 常规 **φ0.3mm 钻孔 / 0.5mm 焊盘** 过孔（孔铜厚 18~20µm）：单个过孔安全承载电流约为 **1.2 ~ 1.5 A**；
- **大电流跨层准则**：当电流超过 1A 时，严禁仅依赖单个过孔！必须按 $1\text{A}/孔$ 的原则放置并联阵列过孔，且过孔之间中心间距建议保持在 0.8~1.2mm，避免热量集中。
