# 电磁兼容（EMC）与 ESD 静电防护设计规范

## 1. 概述
电磁兼容（EMC）包括**电磁干扰（EMI，对外发射）**与**电磁抗扰（EMS，抗外来干扰）**。
静电放电（ESD）是导致现场芯片击穿、闭锁（Latch-up）和固件跑飞最主要的元凶。
本手册指导如何在 PCB 布局布线阶段完成硬件抗扰与电磁兼容合规设计。

---

## 2. 抑制边缘辐射：20H 原则

### 2.1 物理原理
多层板中，电源平面与地平面之间形成一个平行板电容器。但在板卡边缘处，由于电场力线弯曲发散，会产生向外发射的边缘电磁场（Fringing Field）。

### 2.2 20H 规则实施方法
```
  Top / Bottom Layer:   ─────────────────────────
  Layer 2 (GND):        █████████████████████████ (接地平面延伸到板边最外围)
                                     |<- 20*H ->|
  Layer 3 (Power):      █████████████           (电源平面边缘内缩 20H)
```
- **定义**：电源平面的边缘相对接地平面的边缘向内收缩，收缩距离为**两平面间介质层厚度 $H$ 的 20 倍**。
- **效果**：内缩 10H 时边缘电场强度削弱 70%；内缩 20H 时边缘电场强度削弱 **98%**，有效遏制板边高频泄漏。

## 3. 接地屏蔽环与缝合过孔（Ground Stitching Vias）

### 3.1 板边屏蔽过孔阵列
- 在 PCB 裸露边缘（特别是顶层和底层边缘地铜箔），沿板边布置一排接地过孔；
- **过孔间距规则**：过孔中心间距必须满足：
  $$Spacing \le \frac{\lambda_{\text{max}}}{20}$$
  对于系统最高谐波频率为 1 GHz 的场景，波长 $\lambda = 300\text{mm}$，过孔间距应 $\le 15\text{mm}$；在工业紧凑设计中，通常取 **2.0 mm ~ 4.0 mm** 密集缝合，形成类似“法拉第法笼”的屏蔽侧壁。

### 3.2 大面积铺铜去死铜与接地岛加固
- **严禁孤立孤岛铜（Floating Copper）**：任何未连接到地平面的悬空覆铜都是天然的电磁辐射发射源！必须在 EDA 软件中勾选“Remove Isolated Copper（删除未连接的孤岛铜）”；
- 铺铜区域每隔 3~5mm 均匀打上接地缝合过孔，将顶层、底层地铜与内层地紧密锁死，降低接地平面阻抗。

## 4. ESD 静电防护器件（TVS）布局布线铁律

### 4.1 核心防护架构：第一道防线
所有直通机壳外部的接口（USB、接插件、按键、调试探针、电源输入端），引脚入口处必须配置瞬态抑制二极管（TVS）。

### 4.2 走线拓扑对与错（极度关键！）
```
  [ 致命错误：T 型引出走线 ]                 [ 工业标准：先经 TVS 再进芯片 ]
  接插件 ───────────────┬──────> 内部芯片     接插件 ────> [ TVS 焊盘 ] ────> 内部芯片
                        │                                    │ (短粗低阻抗地)
                     [ TVS ]                                (○) Via to GND
                        │
                       (○)
  ▲ 纳秒级静电脉冲下，引线电感呈巨大阻抗！        ▲ 静电必须直接轰击 TVS，绝无法逃逸！
    残压直接击毁内部芯片，TVS 形同虚设！
```
1. **拓扑强制要求**：信号走线必须**直接穿过 TVS 管的贴片焊盘，然后再通往内部保护芯片**，严禁使用分支 T 型走线；
2. **接地回路极短**：TVS 管的接地焊盘到主地平面的引线必须极宽（≥0.5mm）并就近打双接地过孔，确保接地阻抗接近 0Ω；
3. **外壳地与系统地隔离**：金属外壳接插件的外壳接地（Chassis GND）应与系统数字地（Digital GND）在接口处通过高压电容（如 1000pF/2kV）或 RC 并联回路单点隔离，避免外界静电火花直接打入主系统。
