# PCB 层叠规划与阻抗控制指南

## 1. 概述
在高速与高可靠性电路中，PCB 层叠结构（Stack-up）直接决定了：
1. **信号完整性（SI）**：信号是否有低阻抗、连续的回路参考平面；
2. **电源完整性（PI）**：电源与地平面之间的去耦电容效应；
3. **电磁兼容（EMC）**：辐射发射（RE）强度与抗扰度；
4. **机械平整度**：防止板材在回流焊高温下因热膨胀失配而发生翘曲（Warpage）。

---

## 2. 常见多层板黄金叠层方案

### 2.1 4 层板最佳层叠（嘉立创 JLC04161H-7628 标杆）
4 层板共有 2 种常见方案，其性能差异极大：

| 层序号 | 方案 A（强烈推荐：黄金结构） | 方案 B（传统次选：对称但电磁性能差） |
| :--- | :--- | :--- |
| **Layer 1 (Top)** | **Signal 1 / High-Speed / RF** | Signal 1 (Top) |
| *-- Prepreg --* | 7628 / 2116 半固化片 (0.1~0.2mm) | 芯板 Core (0.4~0.6mm) |
| **Layer 2 (In1)** | **GND (完整主接地平面)** | **GND (地平面)** |
| *-- Core --* | 芯板 Core (1.0~1.2mm) | 半固化片 Prepreg (0.2~0.3mm) |
| **Layer 3 (In2)** | **Power / VDD (主电源平面 / 辅助走线)** | **Power (主电源平面)** |
| *-- Prepreg --* | 7628 / 2116 半固化片 (0.1~0.2mm) | 芯板 Core (0.4~0.6mm) |
| **Layer 4 (Bottom)** | **Signal 2 / 低速辅助信号** | Signal 2 (Bottom) |

#### 为什么方案 A 是绝对首选？
1. **最短回流路径**：Top 层所有关键高速器件、晶振和 MCU 的正下方（距表面仅 0.1~0.2mm）就是坚固、完整的 GND 屏蔽平面，回流环路面积几乎为 0，高频辐射衰减达 20~30dB！
2. **易于阻抗控制**：Top 层走线距离 L2 地平面薄，常规 50Ω 微带线线宽适中（约 7~10 mil）；
3. **防止信号跨分割**：In2 层主走电源，必要时可局部走低速控制线，底面 Bottom 也紧邻电源/地参考。

### 2.2 6 层板最佳层叠（高速/复杂工业主板）
- **Layer 1 (Top)**: 高速信号层 1（参考 L2 GND）
- **Layer 2 (In1)**: **GND 1 (完整接地平面)**
- **Layer 3 (In2)**: 信号层 2（内层带状线 Stripline，参考 L2 和 L4 双地，极高抗扰）
- **Layer 4 (In3)**: **Power (主电源平面) / GND 2**
- **Layer 5 (In4)**: **GND 3 / 信号层 3**
- **Layer 6 (Bottom)**: 信号层 4（低速/外设，参考 L5）

## 3. 回流路径（Return Path）与参考平面完整性

### 3.1 核心物理事实
高频交流信号电流（$f > 100\text{kHz}$）在传输线中流动时，其回流电流**不再走电阻最小的直流直线路径**，而是沿着**感抗最小的路径**流动 —— 即**紧贴信号走线正下方的参考平面表面**（集肤效应与互感耦合原理）。

### 3.2 严禁跨分割（Crossing Splits）
```
  [ 错误示范：信号线跨越地平面裂缝 ]
  Signal Trace:  ────────────────────────────> (发生严重信号失真与EMI辐射)
                     ┌──────┐
  GND Plane:     ████│ 裂缝 │█████████████████
                     └──────┘
                      ▲ 回流受阻，形成巨大环路！

  [ 正确示范 1：保持完整连续参考平面 ]
  Signal Trace:  ────────────────────────────>
  GND Plane:     █████████████████████████████ (连续紧密回流)

  [ 正确示范 2：若必须跨越不同电源层，加跨接电容 ]
  Layer 2 (GND): █████████  [100nF]  █████████ (通过高频瓷片电容提供桥接回流)
```
- **危害**：跨分割会导致特征阻抗从 50Ω 暴增至 150Ω 以上，造成严重反射振铃；环路面积剧增，对外辐射强高频电磁波，极易造成 EMC 辐射超标。

## 4. 特征阻抗控制与常用参数计算

### 4.1 微带线（Microstrip）50Ω 计算公式（表层）
$$Z_0 \approx \frac{87}{\sqrt{\varepsilon_r + 1.41}} \ln\left(\frac{5.98 H}{0.8 W + T}\right)$$
- $W$：走线线宽；$T$：铜箔厚度（1 oz 约 0.035 mm）；$H$：走线到底下介质层厚度；$\varepsilon_r$：FR-4 相对介电常数（通常 4.2~4.4）。

### 4.2 嘉立创标准 4 层板 1.6mm 常用阻抗匹配参考表

| 阻抗目标 | 适用信号类型 | 走线层 | 线宽 (W) | 线距 (S) | 参考层 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **单端 50 Ω** | RF 射频天线、高速时钟、单端控制线 | Top / Bottom | **0.25 mm (10 mil)** | 伴随地 ≥ 3W | L2 (GND) |
| **差分 90 Ω** | **USB 2.0 (D+/D-)**、USB 3.0 数据对 | Top / Bottom | **0.15 mm (6 mil)** | **0.18 mm (7 mil)** | L2 (GND) |
| **差分 100 Ω**| **Ethernet 百兆/千兆**、HDMI、CAN-FD | Top / Bottom | **0.127 mm (5 mil)**| **0.20 mm (8 mil)** | L2 (GND) |

## 5. 机械平整度与防板翘曲设计 (Warpage Prevention)
- **对称叠层原则**：芯板厚度、半固化片（PP）张数和型号、各层铜箔厚度必须关于 PCB 中心层绝对对称。
- **残铜率平衡**：Top 层与 Bottom 层的残铜率差异不应超过 15~20%。如果某一表面走线极少，必须填充均匀的接地网格铜皮或孤岛铺铜，防止过回流焊锡炉时单侧收缩造成香蕉板弯曲。
