# 硬件 PCB 设计指令与规范知识库 (PCB Design Instruction)

本项目知识库为嵌入式硬件工程设计提供工业级全生命周期指导，包含标准规范、制造工艺、电源完整性、高速差分、EMC/ESD 防护及 DFM 检查清单。

## 🛠️ 如何在 AI Agent 中调用此技能？
本项目已将上述手册封装为 Antigravity Skill：`pcb-design-instruction`。
当进行 PCB 设计、规则设置、布局走线审查或 DFM 问题排查时，AI Agent 可自动或按需调阅对应分册。
