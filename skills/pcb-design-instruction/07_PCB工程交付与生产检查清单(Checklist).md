# PCB 工程交付与发厂制造检查清单 (DFM Checklist)

## 1. 概述
在完成 PCB 布局布线后、导出 Gerber 及投产下单前，必须逐项执行本清单。
严格按照本检查清单逐条核对，可避免 **99%** 的开路短路、封装选错、极性反接、打样加价和贴片停线问题。

---

## 2. 出厂发板 30 项硬核检查清单

### 分类一：电气连通与 DRC 规则（必须 100% 通过）
- [ ] **1. 全板 DRC 零违规**：在 KiCad/Altium 中以生产厂家的工艺规则文件（如嘉立创 4 层规则）运行 DRC，结果必须为 **0 Errors, 0 Warnings**；
- [ ] **2. 零未连接飞线（Unconnected Nets = 0）**：彻底检查并确保没有任何隐藏飞线或残存悬空网络；
- [ ] **3. 网表一致性（Netlist Parity）**：PCB 与最新原理图（Schematic）的网表核对 100% 一致，无遗漏元件或额外多余走线；
- [ ] **4. 孤岛铜清理（Island Copper）**：运行敷铜检查，确认所有未连接网络的死铜、悬空铜皮已被自动清除；
- [ ] **5. 铺铜网络与热焊盘（Thermal Relief）**：通孔焊盘接地应采用十字花焊盘（防散热过快导致虚焊）；表贴大电流器件采用全覆盖实心铺铜（并打散热过孔阵列）。

### 分类二：机械尺寸、结构与 DFM 工艺
- [ ] **6. 板框层（Edge.Cuts）闭合性**：板框线必须为完全首尾相连的封闭多边形，无重叠线段、无交叉毛刺；
- [ ] **7. 最小钻孔与焊盘检查**：
  - 确认最小通孔钻孔不小于厂家标准（4层板常规免加价推荐 **≥ 0.25 mm**，焊盘外径 **≥ 0.45 mm**）；
  - 确认插件引脚孔径比元器件管脚实测外径大 **0.2 ~ 0.3 mm**；
- [ ] **8. 导电铜皮至板边距离**：
  - CNC 锣边外围走线与焊盘到板框线 $\ge 0.30\text{mm}$；
  - 拼板 V-CUT 线两边到铜皮 $\ge 0.40\text{mm}$；
- [ ] **9. 螺丝孔避让**：所有螺丝孔、螺母定位柱外围 **至少 1.0~1.5mm 范围内**不得有任何走线、焊盘和脆弱阻容元件；
- [ ] **10. 阻焊桥完整性（Solder Mask Dams）**：细间距芯片（QFN/LQFP）引脚间阻焊桥 $\ge 0.10\text{mm}$，无引脚裸连短路风险；
- [ ] **11. 阻焊开窗覆盖检查**：过孔是否按工艺要求盖油（Tented）或塞孔；关键测试点、天线、散热焊盘是否准确开窗裸铜。

### 分类三：丝印、装配与极性标识
- [ ] **12. 极性标识 100% 明确**：
  - 二极管、稳压管、LED 阴极线方向是否醒目；
  - 钽电容、电解电容正极标志是否无歧义；
  - 芯片第 1 脚（Pin 1 Dot）定位圆点是否清晰可见；
- [ ] **13. 丝印防压焊盘**：所有元器件位号（Reference）和文字，均不得压在任何焊接铜皮或测试点上；
- [ ] **14. 字符方向一致性**：丝印位号尽量保持从左到右、从下到上两个方向排列，方便产线装配与售后维修查验；
- [ ] **15. 接插件引脚丝印**：外部接线端子、排针排母、飞线焊盘旁均标有明确功能缩写（如 `GND`, `V3P0`, `SWD`, `TX`, `RX`）；
- [ ] **16. 版本号与工程信息**：板面上清晰丝印项目名称、硬件版本号（如 `LAB7-DL-01 Rev 2.0`）、设计日期与公司/个人标识。

### 分类四：电源、模拟与高速信号布线
- [ ] **17. DC-DC 开关热回路**：输入/输出电容到芯片引脚的开关热回路面积已压缩到极限最小；
- [ ] **18. SW 节点屏蔽**：开关电感与 SW 节点下方内层地完整，无任何敏感信号穿行；
- [ ] **19. 反馈线（FB）隔离**：FB 分压采样线远离电感，且分压电阻就近芯片引脚；
- [ ] **20. 晶振隔离**：晶振紧贴 MCU，表层无其他走线穿行，外壳牢固接地；
- [ ] **21. 差分对等长与连续性**：差分对等长误差在限额内，参考地平面未发生跨分割；
- [ ] **22. TVS 防护拓扑**：外接信号必须先经过 TVS 管焊盘，再进入板内芯片；
- [ ] **23. 大电流载流与并联过孔**：超过 1A 的大电流走线宽度充足，跨层时放置了多个并联过孔（按 1A/孔 计算）。

### 分类五：生产归档文件（Gerber & 贴片资料）
- [ ] **24. Gerber 文件完整性**：
  - 顶/底层走线层（Top/Bottom Copper）；
  - 内层铜箔（Inner Copper Layers）；
  - 顶/底层阻焊层（Top/Bottom Solder Mask）；
  - 顶/底层丝印层（Top/Bottom Silkscreen）；
  - 顶/底层锡膏钢网层（Top/Bottom Solder Paste）；
  - 机械钻孔层（Drill NC / Excellon）；
  - 边框层（Edge.Cuts / Board Outline）；
- [ ] **25. 坐标文件（Pick and Place / Centroid）**：输出包含元件位号、封装、中心坐标 X/Y、旋转角度与贴片面（Top/Bottom）；
- [ ] **26. 交互式 BOM 表**：BOM 物料清单包含位号、规格型号、封装名称、立创商城编号（LCSC Part#）或原厂物料号，且确认**裸铜焊盘与测试点已被剔除出采购清单**；
- [ ] **27. 第三方 DFM 软件复核**：将输出的 Gerber 导入“华秋 DFM”或“嘉立创 DFM 工具”进行二次解析复核，确保无开短路解析异常。
