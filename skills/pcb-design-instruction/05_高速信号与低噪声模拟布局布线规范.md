# 高速信号与低噪声模拟布局布线规范

## 1. 概述
在复杂的嵌入式系统中，微控制器核心高速数字信号（时钟、SWD、SPI、QSPI、USB）与微弱模拟传感器信号（ADC 检测、光敏、温感、运放输入）共存。
本手册针对高速时序保障与极低底噪模拟采集提供设计准则。

---

## 2. 晶体振荡器与时钟电路设计规范

时钟源（无源晶振 Crystal、有源晶振 OSC）是系统最高频、最活跃的电磁辐射源，同时也是对外界干扰最敏感的节点。

### 2.1 晶振布局布线 5 大黄金铁律
1. **就近原则**：晶体必须紧靠 MCU 的 OSC_IN 和 OSC_OUT 引脚放置，连线长度控制在 **≤ 10 mm** 以内；
2. **伴随匹配电容对称性**：两颗匹配起振电容（如 12pF/18pF）应紧挨晶振放置，接地引线直接汇合后就近接入 MCU 的地引脚；
3. **表层禁行区（Keep-Out）**：在晶振及其引线四周 **至少 2.0 mm 范围内，表层严禁穿行任何其他数字或模拟信号线**；
4. **参考地处理**：晶振正下方 Layer 2 必须是**完整的、未被切割的接地平面**，以吸收晶振向下的杂散电容和电磁漏辐射；
5. **外壳接地**：金属外壳晶振的外壳固定焊盘必须多过孔连接主地，提供坚固的屏蔽屏障。

## 3. 差分对（Differential Pairs）走线准则

常见差分信号包括：USB (D+/D-)、CAN/CAN-FD (CANH/CANL)、RS-485 (A/B)、百兆以太网 (TX+/TX-, RX+/RX-)、以太网 MII/RMII 等。

### 3.1 等长、等距与紧耦合
```
   Trace 1 (D+): ────┐      ┌─────────────────────────>
                     │ S    │
   Trace 2 (D-): ────┴──────┴─────────────────────────>
                      ▲ 拐角必须同步伴随转弯，保持间距 S 恒定！
```
1. **等长控制（Length Matching）**：
   - USB 2.0 (480Mbps): 差分对内两线长度误差必须 **≤ 1.25 mm (50 mil)**；
   - 百兆/千兆以太网: 长度误差必须 **≤ 0.5 mm (20 mil)**；
   - 长度补偿蛇形走线（Meander）应**在产生长度偏差的源头拐角处就近补偿**，禁止在走线末端集中补偿。
2. **等距与同层（Same Layer）**：差分对两根信号线必须在同一信号层走线，严禁一根在顶层、一根在底层；间距 $S$ 在全程保持严格恒定。
3. **过孔伴随（Via Shielding）**：若差分对必须打孔换层，**两根线必须同时打孔**，并在差分过孔旁边打一个接地伴随过孔（Ground Stitching Via），确保回流路径在换层时连续。

## 4. 模数混合电路（Mixed-Signal）接地与隔离

### 4.1 单块统一地（Solid Ground） vs 分割地（Split Ground）
在传统设计中常有人将地平面机械切割为“数字地（DGND）”和“模拟地（AGND）”，但若控制不当，信号跨越地缝会造成灾难性的 EMI 事故。

#### 现代工业推荐做法：**统一完整地平面 + 严格物理区域隔离**
```
┌────────────────────────────────────────────────────────┐
│                   完整连续的主接地平面                  │
│  ┌──────────────────────────┐  ┌────────────────────┐  │
│  │       数字系统区域       │  │    模拟传感区域    │  │
│  │ · MCU / 高频开关         │  │ · 高精度传感器     │  │
│  │ · 强瞬态电流回路         │  │ · 仪表放大器       │  │
│  │                          │  │ · ADC 采样前端     │  │
│  │   【数字回流局限在此】   │  │【模拟小回流在此】  │  │
│  └──────────────────────────┘  └────────────────────┘  │
│               ▲                           ▲            │
│               └──── 物理空间自然分离 ──────┘            │
└────────────────────────────────────────────────────────┘
```
- **核心逻辑**：只要高频数字信号不穿入模拟区域，其回流电流就只会聚集在自身走线正下方的地平面中，绝不会侵入模拟区域的地！
- **桥接滤波**：ADC 芯片的模拟供电引脚（$V_{DDA}$ / $V_{REF}$），通过 **铁氧体磁珠（Ferrite Bead，如 600Ω@100MHz）+ Π 型滤波电容（10µF + 100nF）** 从系统主数字电源隔离取电。

## 5. 微弱模拟小信号防护
- **采样电阻就近原则**：分压采样电阻（如电池电压采样、热敏/光敏采样）必须紧贴 MCU/ADC 引脚，使进入引脚前的高阻抗节点走线最短；
- **RC 滤波电容放置**：抗混叠滤波电容（如 10nF/100nF）必须紧靠 ADC 引脚并就近下地，直接滤除引线上感应的高频杂波。
