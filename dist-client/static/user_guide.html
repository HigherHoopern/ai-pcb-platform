01

第一步：创建新工程项目 & 自定义配置「工程文件目录」

对应界面位置：顶部导航栏「+ 新建」按钮 & 左侧边栏最上方「EXPLORER · 工程文件目录」

1.1 如何创建一个全新的独立硬件工程？
  1. 点击页面右上角顶部工具栏的 + 新建 按钮（或者点击左侧「① 项目工作台」里的 「+ 新建软硬件协同工程」）。
  2. 在弹出的向导窗口中：
    • 工程英文标识名：输入例如 Smart-Temp-Fan-01
    • 工程模板选择：新手推荐选择 工业温湿度烟雾报警器 (env_alarm) 或 直流无刷电机驱动板 (motor_ctrl)（如果想完全从零配起可选 空白工程 (custom_blank)）。
    • 目标主控 MCU：推荐选择 STM32F103C8T6 (LQFP-48, 64KB Flash) 或 STM32G030F6P6 (TSSOP-20)。
    • 板框尺寸：默认输入宽 60 mm × 高 40 mm，双面板（2 Layers）。
  3. 点击 「立即创建并初始化脚手架」，系统会在 3 秒内自动为您生成包含 hardware/、firmware/、docs/、spec.json、pinout.json 的完整工程结构！
1.2 如何在「EXPLORER · 工程文件目录」里自己新增/修改/删除文件夹和文件？

点击左侧边栏最上方的 「EXPLORER · 工程文件目录」，其他模块会自动折叠，为您展开完整的工程目录树：

  • 📁 新建文件夹：点击目录树顶部的 📁+ 新建文件夹 按钮（或鼠标悬浮在任意文件夹行右侧点击 📁+），选择父目录（如 / 根目录、firmware、hardware、docs），输入文件夹名称（支持多级路径如 Middlewares/Filter），点击 「立即创建文件夹」。
  • 📄 新建文件：点击目录树顶部的 📄+ 新建文件 按钮（或悬浮在任意文件夹右侧点击 📄+），输入文件名（如 pid_ctrl.c、pid_ctrl.h、README.md），系统会自动为您生成带头文件保护宏的标准 C99 代码骨架并打开在线编辑器！
  • ✏️ 重命名或移动位置：鼠标悬浮在目录树任意文件夹或文件上，点击右侧出现的 ✏️（铅笔图标），即可直接修改文件名或修改所在目录路径。
  • 🗑️ 删除文件夹或文件：鼠标悬浮在任意节点上，点击右侧的 🗑️（垃圾桶图标） 确认后即可安全删除。

第二步：确认或蒸馏行业设计规范 Skill（让 AI 懂嘉立创工艺与 STM32 规范）

对应界面位置：左侧边栏「AI 自动化与插件生态」➔「🧩 Skill 知识蒸馏」

在开始画板和写代码前，您可以点击左侧边栏的 「🧩 Skill 知识蒸馏」 查看已为您内置挂载的专业工程知识包：

📘 pcb-design-skill（已默认激活） 324页全书蒸馏

提炼自 324 页《嘉立创 从设计到量产：电子工程师PCB智造实战指南》，包含双面板线宽/线距红线（信号 ≥0.25mm，电源 ≥0.5mm，安全间距 ≥0.15mm）、去耦电容就近摆放及 SMT 基础库选型规则。

📘 stm32-hal-ll-driver-expert（已默认激活） C99 裸机规范

内置 STM32 寄存器/LL/HAL 级 C99 编程范式，强制要求 100% 引用 bsp_pinout.h 引脚宏，采用非阻塞三态有限状态机（FSM）与消抖算法。

💡 如果您手头有新的传感器 Datasheet PDF 或企业内部硬件规范文档，也可以点击右上角 「+ 上传资料蒸馏新 Skill」，调用本地 Qwen3.8-27B 大模型分章节深度蒸馏并一键挂载。

03

第三步：在「② 规格与引脚 (SSOT)」输入硬件需求并锁定单一事实源

对应界面位置：左侧边栏「核心研发流程」➔「② 规格与引脚 (SSOT)」

这是整个软硬件协同最关键的一步！点击左侧边栏进入 「② 规格与引脚 (SSOT)」，按以下三小步操作：

3.1 在「自然语言硬件需求输入区」粘贴您的项目需求（可直接点击下方按钮复制示例）： 
设计一款基于 STM32G030F6P6 (TSSOP-20) 的智能温湿度与烟雾安全报警控制板：
1. 供电与尺寸：Type-C 5V 输入，经 AMS1117-3.3 降压为 3.3V；板框尺寸 60mm × 40mm，双面板，四角 R2.0mm 圆角；
2. 引脚分配要求：
   - PA0 (ADC_IN0): 连接 MQ-2 烟雾传感器模拟输出 (SMOKE_ADC)
   - PA1 (ADC_IN1): 连接电池电压分压检测 (VBAT_SENSE)
   - PA4 (GPIO_Output): 红色超标报警指示灯 (LED_ALARM)
   - PA5 (GPIO_Output): 绿色正常运行心跳灯 (LED_STATUS)
   - PA6 (TIM3_CH1): 有源/PWM 蜂鸣器驱动引脚 (BUZZER_PWM)
   - PA7 (GPIO_Input): 手动消音与自检按键 (KEY_MUTE，低电平有效)
   - PB6 / PB7 (I2C1_SCL / I2C1_SDA): 连接 SHT30 数字温湿度传感器
   - PA9 / PA10 (USART1_TX / USART1_RX): 115200 串口调试与状态上报

粘贴后，点击 「✨ AI 智能提炼硬件规格与引脚」 按钮，大模型会自动解析出主控型号、板框尺寸以及全部引脚分配表！

3.2 在下方「引脚分配矩阵 (PinMux Table)」检查或手工增删引脚：
  • 您可以直接在表格里修改任意引脚号（如把 PA4 改为 PB0）、网络名称（如 RELAY_CTRL）或复用功能，也可以点击 「+ 新增引脚行」。
  • 点击 「🔍 引脚冲突预检」：系统会自动校验是否存在同一物理引脚被重复分配给两个不同网络、或误占用了 SWD 调试脚（PA13/PA14）。
3.3 点击「🔒 锁定规格并同步生成 bsp_pinout.h」：

点击该按钮后，系统会同时完成三件事：
① 将硬件规格写入 spec.json；
② 将引脚映射表写入 pinout.json；
③ 全自动生成 C 语言硬件抽象头文件 firmware/Drivers/bsp_pinout.h（内含全部 PIN_<网络名>_PORT_NAME、PIN_<网络名>_PIN_INDEX、PIN_<网络名>_BIT_MASK 宏定义），确保后续画出的 PCB 和写出的 C 语言程序 100% 物理引脚对齐！

第四步：在「③ PCB 硬件工坊」生成电路板、执行 DRC 自愈并导出嘉立创打样包

对应界面位置：左侧边栏「核心研发流程」➔「③ PCB 硬件工坊」

4.1 四合一画布零滚动切换预览

进入 「③ PCB 硬件工坊」 后，在画布左上角可随时切换 4 个核心视图：

  • 🖼️ 3D 正反面渲染：查看 KiCad 光线追踪生成的顶层（F.Cu）与底层（B.Cu）3D 实物效果图（若未生成可点击上方 🔄 刷新视图）。
  • 📐 2D 铜皮走线：查看顶/底层铜皮走线、过孔环、焊盘与板框倒角矢量图（SVG）。
  • 🔌 2D 原理图：查看自动生成的 .kicad_sch 原理图与引脚网络连线框图。
  • 📋 BOM 与立创选型：在线查看和编辑每个元器件的 立创商城 C 编号（LCSC Part#）。
4.2 DRC 规则检查、冲突自愈与嘉立创导出
  1. 点击「✅ 运行 DRC」：调用本机 KiCad 10 官方 CLI 执行静态设计规则检查，查看 DRC 违规数 与 未连接飞线数。
  2. 点击「🩺 DRC 冲突自愈」：若发现任何间距违规或未连接飞线，点击此按钮，AI 会自动重算安全走线走廊并修复冲突，直至达成 0 违规 / 0 飞线。
  3. 切换到「📋 BOM 与立创选型」点击「一键转立创基础库」：自动将阻容、LDO 等通用器件替换为嘉立创 SMT Basic（基础库），帮您省下每款 20 元的扩展库换料费！
  4. 点击绿色主按钮「📦 导出嘉立创打样包」：一键生成可直接上传嘉立创下单助手的 _JLCPCB_Gerber.zip、_JLC_BOM.csv 和 _JLC_CPL.csv（贴片坐标文件）。
05

第五步：在「④ C99 固件工坊」编写 C 语言程序、ARM-GCC 编译与在线波形仿真

对应界面位置：左侧边栏「核心研发流程」➔「④ C99 固件工坊」

5.1 认识 C99 固件工坊的 4 个核心源文件标签：
  • Drivers/bsp_pinout.h：由第三步 SSOT 自动生成的引脚宏头文件（只读事实源，包含所有 PIN_<NET>_* 宏）。
  • Inc/app_config.h：定义传感器报警阈值（如烟雾毫伏阈值、温度报警阈值）和三态状态机枚举（STATE_NORMAL / STATE_ALARM_LATCHED / STATE_ALARM_MUTED）。
  • App/app_state_machine.c：核心业务主战场！实现传感器消抖采样、状态机流转以及全引脚同步输出函数 App_Sync_All_SSOT_Pins()。
  • App/main.c：裸机启动向量表、GPIO 寄存器初始化与 while(1) 主循环（同时支持宿主机沙箱仿真）。
5.2 一键生成骨架与在线编辑 C 代码
  1. 点击工具栏「重置 C99 骨架」：如果您刚才在第三步新增或修改了引脚，点击此按钮，系统会自动把所有新引脚的 PIN_* 宏写入 app_state_machine.c，使页面上方的 「SSOT 引脚宏覆盖率」立即达到 100%（绿色徽章）！
  2. 在线修改代码并按 ⌘S / Ctrl+S 保存：您也可以点击任意引脚胶囊，编辑器会自动滚动并高亮该引脚在 C 代码中的调用行（点击顶部 ◫ 分屏 还能左看 PCB、右写 C 代码同屏联动）。
5.3 ARM-GCC 交叉编译与在线状态机波形仿真
  1. 点击蓝色主按钮「🔨 编译固件 (GCC)」：系统立即调用本机 arm-none-eabi-gcc -std=c99 -Os 编译工程，生成 .elf / .hex / .bin，并展示 Flash 与 SRAM 占用百分比。
  2. 点击「🔮 在线仿真 (Sim)」：屏幕底部会展开 「🔮 SIMULATOR · C99 状态机在线仿真」 面板：
    • 点击左侧 正常 / 超标报警 / 消音锁存 预设按钮，或拖动 ADC 烟雾 / 温度 / 电压滑块；
    • 中间逻辑分析仪会实时画出 12-Tick 每个物理引脚的高低电平跳变波形，右侧 Virtual UART 实时打印串口日志！

第六步：如果生成的 PCB 或 C 语言程序有问题？唤起右侧「🧭 维吉尔 · Virgil」边栏

对应界面位置：屏幕最右侧边缘竖排把手「‹ 🧭 维吉尔 · Virgil」或顶部导航栏「🧭 维吉尔 · Virgil」按钮

取自但丁《神曲》中象征理性与精湛技艺的领路人——「🧭 维吉尔 · Virgil」 是驻守在您屏幕右侧的可折叠 AI 协同领航台。无论您是在看 PCB 还是在写 C 代码，随时点击屏幕右边缘把手展开它（不需要时点击 收起 › 即可释放 100% 画布宽度）：

📐 场景 A：对 PCB 电路板不满意（切到「📐 PCB」模式） 自动重绘 + DRC

点击上方 📐 板框/尺寸、📍 器件布局、⚡ 走线/DRC 标签，或直接复制以下指令发给维吉尔：

"【板框与尺寸调整】请将 PCB 板框改为 68x42mm，四角倒角 R2.5mm，电源线加粗到 0.6mm 并重新渲染 3D 视图"
"【元件位置与布局优化】蜂鸣器离主控太近了，请把蜂鸣器移到板子右上角 (52, 12) 附近，重新规划 45° 走线并跑 DRC"
"【走线间距与DRC修复】结合 @drc 自动诊断并修复当前全部间距冲突与未连接飞线，同时把阻容器件全换成嘉立创基础库"
💻 场景 B：对 C99 程序不满意（切到「💻 C99」模式） 自动改码 + GCC 编译

点击上方 🔨 编译修复、🔄 状态机/阈值、📌 引脚驱动 标签，或直接复制以下指令发给维吉尔：

"【状态机与报警阈值调整】请把烟雾报警阈值改为 1800mV，温度超标阈值改为 60°C，连续 3 次采样超标才触发报警锁存，并重新调用 GCC 编译"
"【补全漏写引脚C99驱动】检查 @pinout 与 bsp_pinout.h，补全所有尚未在状态机中调用的引脚初始化与驱动逻辑，确保 100% 覆盖率"
"【GCC编译报错修复】请分析当前 @gcc 编译输出日志，修复语法错误或未定义宏并重新编译验证"
🛡️ 安全护航机制（自动快照 + Diff + 一键回滚）：维吉尔每次修改您的 PCB 或 C 代码前，都会自动创建工程快照。您可以点击气泡下方的 🔍 并排 Diff 审查 查看修改前后的代码对比，如果不满意，点击 ↩️ 撤销回滚 即可毫秒级无损还原！

第七步：一键运行「⚡ 全自动协同流水线」并打包下载全套量产交付物

对应界面位置：顶部导航栏「⚡ 全自动构建」按钮 & 左侧边栏「全自动协同流水线」

当您希望系统一气呵成完成所有校验并生成最终签署报告时，直接点击顶部导航栏最右侧的蓝色按钮 ⚡ 全自动构建：

  1. 平台会自动按序执行 5 个阶段：Stage 1 需求与引脚 SSOT 锁存 ➔ Stage 2 PCB 布局与 2D/3D 渲染 ➔ Stage 3 KiCad DRC 审查与冲突自愈 ➔ Stage 4 C99 固件生成与 ARM-GCC 交叉编译 ➔ Stage 5 交付验收报告签署。
  2. 全部变成绿色 COMPLETED 后，切换到 「① 项目工作台」 点击右上角 「📦 一键打包导出全套交付物 (.zip)」，即可下载包含： KiCad 原理图/PCB 源文件 + 嘉立创 Gerber/BOM/CPL 制板贴片包 + 3D 渲染图 + C99 全部源码 + ARM-GCC 编译出的 .elf/.hex/.bin 烧录固件 + 交付验收报告 的完整归档包！
