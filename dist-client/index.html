              二、 PCB 硬件设计详细使用说明（从需求建工、KiCad 版图到嘉立创 SMT 量产投产）
            

            

              按照以下 4 个步骤操作，即使没有复杂的 EDA 脚本经验，也能快速完成具备 0 DRC 违规、符合嘉立创量产工艺的电路板设计。
            

          

          
        


        
        

          
          

            

              PCB 第 1 步 · 建立硬件工程
              
            

            
选择行业预设模板 或 上传自然语言需求书

            
    
              
  • 方式 A（最快，推荐新手）：点击顶部导航栏 + 新建 或左上角工程树旁的文件夹加号，从 5 大行业模板（温湿度烟雾传感报警节点、BLDC 电机驱动、ESP32-S3 物联网节点、超低功耗穿戴设备、自定义空白板）中选择一个，点击「立即创建」即可自动生成全套原理图、PCB 与固件。
    • 
              
  • 方式 B（AI 需求蒸馏）：进入 「② 规格与引脚 (SSOT)」，上传 .md / .txt / .pdf / .docx 需求文档，由本地 Qwen3.8-27B 大模型自动提炼主控芯片、外设器件清单与推荐引脚分配。
    • 
            

          


          
          

            

              PCB 第 2 步 · 锁定机械规格与引脚 (SSOT)
              
            

            
设定板框尺寸 / 层数 / 电源拓扑并通过引脚冲突预检

            
    
              
  • 机械与电源参数：在「② 规格与引脚」中填写电路板长宽（如 65.0 × 45.0 mm）、板层数（2层双面板 或 4层含内电层）、供电输入（如 USB Type-C 5V 转 LDO 3.3V）。
    • 
              
  • 物理引脚冲突拦截：在引脚映射表中编辑 引脚号 (如 PA0)、网络名 (如 ADC_SMOKE) 与 方向/外设功能。若同一物理引脚被分配给两个不同网络，系统会立即标红拦截。
    • 
              
  • 一键锁定同步：点击「保存并锁定 SSOT」，系统同时写入 spec.json、pinout.json 并自动生成 C 头文件 bsp_pinout.h。
    • 
            

          


          
          

            

              PCB 第 3 步 · 2D/3D 检视与 DRC 规则自愈
              
            

            
零滚动切换 3D 光追 / 2D 走线 / 原理图，一键 DRC 冲突自愈

            
    
              
  • 多视图实时预览：在「③ PCB 硬件工坊」画布上方可随时切换 📦 3D 渲染预览 (Top/Bottom 正反面)、🟩 2D PCB 走线图、📄 原理图 (SCH)。
    • 
              
  • KiCad 官方 DRC 与 AI 自愈：点击工具栏 运行 DRC 检查 调用本机 KiCad 10 CLI 审计线距、孔径与未连接飞线；若存在违规，点击 ✨ AI 自动冲突自愈 即可自动重排走线与退让间距直至 0 DRC 违规。
    • 
              
  • 自然语言修改版图：打开右侧 AI 助手（挂载 @pinout @drc），直接输入如“把电路板尺寸改为 70x50mm 并把蜂鸣器移到板边 (55, 20)”，AI 将自动修改版图并重跑 DRC。
    • 
            

          


          
          

            

              PCB 第 4 步 · 嘉立创 BOM 优选与制板包导出
              
            

            
智能替换嘉立创 SMT 基础库 (Basic) 省换料费，导出 Gerber 投产

            
    
              
  • 立创 SMT 基础库优化：切换到画布的 📋 立创 BOM 与贴片表 视图，点击 ⚡ 智能优选立创基础库，系统会自动将常用阻容感与芯片匹配为嘉立创 Basic（基础库） 编号（如 C25804），每减少一款扩展库（Extended）器件即可在 SMT 打样时节省 ¥20 换料费。
    • 
              
  • 一键导出投产制板包：点击 📦 导出嘉立创 Gerber+BOM+CPL，在 hardware/out/ 下生成标准 *_JLCPCB_Gerber.zip、BOM 表与贴片坐标表，可直接上传嘉立创下单助手生产。
    •

              三、 C 语言 (C99) 嵌入式固件设计详细说明（五层架构、SSOT 宏规范、编译与在线仿真）
            

            

              本平台采用工业级 C99 裸机非阻塞有限状态机 (FSM) + SSOT 硬件抽象层解耦架构，同一套 C 代码既可由 arm-none-eabi-gcc 编译烧录至真机 MCU，又可在浏览器内一键运行状态机波形仿真。

              ⚡ 准则二：采用非阻塞三态有限状态机（禁用长延时死循环）
              实时响应 + 在线可仿真
            

            

              为保证传感器采样、按键消抖与报警输出的实时性，并在底部 🔮 SIMULATOR 中输出 12-Tick 逻辑分析仪波形，请使用 App_FSM_Step() 周期性步进架构：
            

            
void App_FSM_Step(app_fsm_ctx_t *ctx, uint16_t adc_mv, int16_t temp_c, uint8_t key_mute) {
  ctx->tick_count++;
  bool hazard = (adc_mv >= APP_SMOKE_ALARM_THRESHOLD_MV) || (temp_c >= 55);

  switch (ctx->state) {
    case STATE_NORMAL:          /* 正常监测态：绿灯闪烁，蜂鸣器关 */
      if (hazard && (++ctx->debounce_cnt >= 2U)) {
        ctx->state = STATE_ALARM_LATCHED; /* 连续超标确认 -> 锁存报警 */
      }
      break;
    case STATE_ALARM_LATCHED:   /* 超标报警锁存态：红灯亮 + 蜂鸣器高频鸣叫 */
      if (key_mute) ctx->state = STATE_ALARM_MUTED; /* 按下消音键 -> 静音态 */
      break;
    case STATE_ALARM_MUTED:     /* 手动消音降级态：保留红灯警示，关闭蜂鸣器 */
      if (!hazard) ctx->state = STATE_NORMAL;       /* 险情解除 -> 恢复正常 */
      break;
  }
}
